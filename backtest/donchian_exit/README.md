# 唐奇安出場回測

進場用你從網站匯出的實際單,出場換成不同規則,拿真實 1 小時 K 線重新跑一遍,比較哪種出場比較好。
只用 Python 內建模組,不用另外裝套件。

## 用法

1. 網站 → 唐奇安 / 唐奇安v2 頁 → 右上「⬇ 匯出 CSV」。兩本可以一起給,同一筆進場會自動去重。
2. 在這個資料夾執行:

```bash
py dc_exit_bt.py --csv donchian.csv donchianv2.csv
py dc_exit_bt.py --csv donchian.csv donchianv2.csv --out detail.csv   # 另存每筆單在每種規則下的結果
```

連不到 Binance 即時 API(例如所在地區被擋,回 451)時加 `--source vision`,改用 Binance 公開歷史檔
(data.binance.vision,只到昨天,今天進場的單會跳過)。K 線存在 `kline_cache/`,重跑不會重抓。

## 怎麼看結果

- 最上面的「驗算」:用初版 / v2 的規則重播,要跟網站記錄的結果幾乎一樣(≥ 95% 相差 ≤ 0.15R),
  代表重播是對的,下面的比較才可信。
- R = 進場到初始停損的距離。每種規則列出平均每筆幾 R、勝率、「賺過 1R 又變負」的筆數、回吐。
- 「前半 / 後半」= 依進場時間把單切兩半。**兩半都比 v2 好才算穩**,只有一半好通常是剛好碰到那段行情。

## 目前比較的規則

| 名稱 | 規則 |
|---|---|
| V1 | 初版:12 根通道 |
| V2 | v2 現行:12 根通道 + 吊燈 3×ATR(目前 ATR) |
| V2cap / V2cap2 / V2cap1.5 | 吊燈 3 / 2 / 1.5 × ATR,ATR 只准變小(上限 = 進場 ATR) |
| V2hi | 吊燈 3×ATR 只准變小,最高點用盤中高點 |
| Tight2/3 | 賺到 2R 後吊燈改 2×、3R 後改 1.5×進場 ATR |
| Part2/4 | 到 2R 平 1/3、4R 再平 1/3 |
| Part2half | v2 現行 + 到 2R 平一半 |
| Climax | 爆量反轉 K:賺過 1.5R 後,量 ≥ 3 倍均量且收在不利的 40% → 出 |
| Wick | 創進場後新高、上影 ≥ 60% 全距 → 出 |
| VolLow | 收盤跌破進場後爆量 K 的低點 → 出 |
| Dist3 | 上面三種出貨訊號全開 |

要加新規則:在 `RULES` 加一行 `rule(...)`,參數說明在 `rule()` 的註解。
